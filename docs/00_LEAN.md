## 세그먼트별 가설·검증 (D20, D25)
| 항목 | ① AI 강의 수강생 | ② 1인 사업자 |
|---|---|---|
| 획득 경로 | 강의 번들 코드로 가입 (D20) | 랜딩 → 사전예약 (D20) |
| 가설 | 강의를 들은 수강생은 SSR+ 단계 학습 + 7일 세팅 계획을 실제로 끝까지 따라 하고, 계속 쓰고 싶어 한다 [추정] | 1인 사업자는 SSR+ 학습 + 개인 대시보드를 기기 간 저장해 주는 서비스에 구독료를 낼 의향이 있다 [추정] |
| 검증 방법 | 수강생 30명에게 번들 코드 배포 → 7일 계획 사용 → 종료 설문 | 랜딩 2주 운영(광고 포함) → 사전예약 폼 집계 |
| 통과 기준 (재량) | 7일 계획 완주 **40% 이상** + "계속 쓰겠다" **60% 이상** | 방문 1,000명 중 사전예약 **30건(3%) 이상** |
| 측정 | `days` 7/7 사용자 비율, 종료 설문 | 랜딩 방문 수, 사전예약 폼 제출 수 |
| 결과 | 검증 전 | 검증 전 |
