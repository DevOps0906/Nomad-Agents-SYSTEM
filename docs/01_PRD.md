## 1. 한 줄 정의
Claude를 쓰는 한국어 개인·1인 사업자[추정]가 SSR+(스킬·세컨드 브레인·루틴·익스텐션) 4단계를 7일 계획으로 갖추고, 그 진행·아이디어·콘텐츠를 **계정에 저장해 어느 기기에서나 이어 쓰는** 개인 AI 업무 대시보드.
- As-Is: 단일 HTML, 저장은 브라우저 localStorage 3키뿐, 인증·서버 없음(SITE_FACTS#8).
- To-Be: 화면·디자인·문구는 1:1 동일(D1). 저장·인증·데이터 출처만 바꾼다(D4~D6). 신규는 로그인 진입·권유(D23·D24), 두뇌 연동(D22), 관리자 화면(D21)뿐.

## 6. 하지 않을 것 · 금지 문구
- 화면·디자인·문구를 아티팩트와 다르게 바꾸지 않는다(D1). 신규는 T1~T3·B1·P1·AD1~AD5와 상단 바 로그인 버튼·계정 메뉴만.
- 로그인 권유로 체험을 막지 않는다(항상 "예시로 계속 보기", D24).
- 두뇌 연동에서 Markdown 본문을 서버로 올리지 않는다(D22). 요약도 본문에서 자동 추출하지 않는다(D37).
- 로그인 중 저장이 실패해도(세션 만료·오프라인 포함) localStorage로 떨어지지 않는다. 메모리 대기열에서 다시 시도한다(D33).
- Pro 기능을 화면에서만 숨기지 않는다. 게이트는 DB 정책·함수에 둔다(D31).
- AI·외부 API를 호출하지 않는다. 프롬프트는 복사만(D9).
- 사용자가 카탈로그(SSR·ArtCraft·가이드·7일 기본값·팔레트·탐색기)를 수정하지 않는다. 수정은 관리자 화면 AD1~AD5(D4, D21, AD5는 MVP-1) — MVP-2 범위 밖 카탈로그는 마이그레이션(D39).
- MVP에서 루틴 실제 예약·실행·알림, 팀 공유, 카드 결제를 만들지 않는다(D6·D30). Pro는 체험·번들 코드로만 부여.
- 금지 문구: "루틴 자동 실행" 등 실제 실행을 암시하는 표현(토글은 상태값만, SITE_FACTS#8) · 근거 없는 효과 수치.
