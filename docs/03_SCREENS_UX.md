> S00~S13·M1~M6은 사이트(`app/index.html`)와 1:1(D1)이라 사이트에 없는 요소를 넣지 않는다. 아래 지적은 의도된 예외다. 재검사: `plan2spec docs --out docs/spec --diagrams docs/diagrams`.
