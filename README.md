# Nomad-Agents-SYSTEM

Nomad-Lab AI 업무 시스템 — SSR+(Skill · Second brain · Routine · Extension) 대시보드.

- `app/index.html` : 단일 파일 앱 (three.js r128, GSAP 3.12.5는 CDN). 브라우저로 바로 열면 됩니다. `guide/`의 PDF 쪽 이미지를 같은 폴더에서 불러옵니다.
- `src/` : 화면 소스 조각 (style.css, body.html, app.js, home3d.js)과 가이드에서 추출한 프롬프트·페이지 텍스트(JSON)
- `docs/PLAN.md` : 기획 및 디자인 구조
